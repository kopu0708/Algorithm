## 1차원 구간 합

배열의 특정 구간 합(연속된 부분)을 구하는 것. `{2, 3, 4, 5, 6}`이 있으면 "1번째 인덱스부터 3번째 인덱스까지의 합"을 구하는 식.

### 문제 상황

매번 구간이 주어질 때마다 처음부터 다시 더하면:

```csharp
static int RangeSum(int[] arr, int start, int end)
{
    int sum = 0;
    for (int i = start; i <= end; i++)
    {
        sum += arr[i];
    }
    return sum;
}
```

이건 한 번 호출할 때마다 O(N)이다. 이걸 수만 번 반복하면 시간 복잡도가 **O(N × 질문 횟수)**가 되어 시간 초과가 난다.

### 합 배열(Prefix Sum) 만들기

배열을 하나 더 만들어서 각 인덱스까지의 누적 합을 저장해둔다.

```
{1,2,3,4,5} → 합 배열: {0,1,3,6,10,15}
```

이렇게 구해두면 이후 어떤 구간이든 **뺄셈 한 번**으로 바로 구간 합을 구할 수 있다.

`S[i] = A[0] + A[1] + ... + A[i]`라고 할 때:

```
S[j] - S[i-1] = i에서 j까지의 구간 합
```

합 배열을 구해두면 시간 복잡도가 **O(1)**로 감소한다.

> ⚠️ 합 배열을 만들 때는 원본 배열보다 **한 칸 크게** 만들어야 한다. `S[i-1]`에서 `i=0`일 때 `S[-1]`이 되어 범위를 벗어나는 걸 막기 위해서다. 맨 앞에 `0`을 패딩으로 넣어두면 이 문제를 피할 수 있다.

### 실전 코드 (1차원)

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        int[] arr = { 1, 2, 3, 4, 5 };
        int[] prefix = new int[arr.Length + 1];

        for (int i = 0; i < arr.Length; i++)
        {
            prefix[i + 1] = prefix[i] + arr[i];
        }
        // prefix = [0, 1, 3, 6, 10, 15]

        // 1번째부터 3번째 인덱스까지의 합 (2+3+4=9)
        Console.WriteLine(RangeSum(prefix, 1, 3));  // 9
    }

    // S[j+1] - S[i] = arr[i]부터 arr[j]까지의 구간 합
    static int RangeSum(int[] prefix, int i, int j)
    {
        return prefix[j + 1] - prefix[i];
    }
}
```

**실전 문제 형태 (배열 크기·질의 개수 입력, 여러 쿼리 처리)**

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        string input = Console.ReadLine();
        int[] a = Array.ConvertAll(input.Split(' '), int.Parse);  // 배열 크기, 질의 개수

        string arrInput = Console.ReadLine();
        int[] arr = Array.ConvertAll(arrInput.Split(' '), int.Parse);

        int[] prefix = new int[arr.Length + 1];
        for (int i = 1; i < prefix.Length; i++)
        {
            prefix[i] = prefix[i - 1] + arr[i - 1];
        }

        for (int i = 0; i < a[1]; i++)
        {
            string queryInput = Console.ReadLine();
            int[] query = Array.ConvertAll(queryInput.Split(' '), int.Parse);
            int answer = prefix[query[1]] - prefix[query[0] - 1];  // 1-based 인덱스 보정
            Console.WriteLine(answer);
        }
    }
}
```

## 2차원 구간 합

### 왜 한 줄씩 계산하면 안 되는가

2차원 배열의 특정 사각형 영역 합을 구하는 문제를 처음 보면, "행마다 1차원 구간 합을 만들어서 필요한 행들을 더하면 되지 않을까" 하는 생각이 먼저 든다. 하지만 이렇게 하면:

```csharp
// 각 행마다 1차원 prefix를 만들어도
int sum = 0;
for (int row = r1; row <= r2; row++)
{
    sum += rowPrefix[row, c2] - rowPrefix[row, c1 - 1];  // 필요한 행만큼 다시 반복
}
```

**질문 1번당 O(N)** (행 개수만큼)이 되어버려서, 애초에 얻으려던 "O(1)에 답 구하기"를 못 얻는다. 코드도 길어지고 시간복잡도도 커지는 걸 확인하고 나서 방향을 바꿔야 했다.

### 2차원 합 배열 공식

```
D[i][j] = D[i][j-1] + D[i-1][j] - D[i-1][j-1] + A[i][j]
```

두 축(행, 열)으로 각각 더하고, 겹치는 부분을 한 번 빼준 다음, 지금 칸의 값을 더하는 식이다.

**직접 검증 (matrix = {1,2},{3,4}):**

```
prefix[1,1] = 0 + 0 - 0 + 1  = 1   ✓ (왼쪽 위 1칸)
prefix[1,2] = 1 + 0 - 0 + 2  = 3   ✓ (1행 1~2열: 1+2)
prefix[2,1] = 0 + 1 - 0 + 3  = 4   ✓ (1~2행 1열: 1+3)
prefix[2,2] = 3 + 4 - 1 + 4  = 10  ✓ (전체 합: 1+2+3+4)
```

**구간(사각형 영역) 합 구하기:**

```
S[r2][c2] - S[r1-1][c2] - S[r2][c1-1] + S[r1-1][c1-1]
```

1차원의 `S[j] - S[i-1]`과 같은 원리인데, 사각형이라 뺄셈이 두 번 필요하고 겹치는 부분을 다시 더하기로 보정해야 한다 (포함-배제 원리).

### 실전 코드 (2차원)

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        string input = Console.ReadLine();
        int[] a = Array.ConvertAll(input.Split(' '), int.Parse);  // 배열 크기, 질의 개수

        int[,] matrix = new int[a[0], a[0]];

        for (int i = 0; i < a[0]; i++)
        {
            string[] row = Console.ReadLine().Split(' ');
            for (int j = 0; j < a[0]; j++)
            {
                matrix[i, j] = int.Parse(row[j]);
            }
        }

        int[,] prefix = new int[a[0] + 1, a[0] + 1];

        for (int i = 1; i < a[0] + 1; i++)
        {
            for (int j = 1; j < a[0] + 1; j++)
            {
                prefix[i, j] = prefix[i, j - 1] + prefix[i - 1, j] - prefix[i - 1, j - 1] + matrix[i - 1, j - 1];
            }
        }

        for (int i = 0; i < a[1]; i++)
        {
            string queryInput = Console.ReadLine();
            int[] xy = Array.ConvertAll(queryInput.Split(' '), int.Parse);
            // xy[0]=r1, xy[1]=c1, xy[2]=r2, xy[3]=c2

            int result = prefix[xy[2], xy[3]]
                       - prefix[xy[0] - 1, xy[3]]
                       - prefix[xy[2], xy[1] - 1]
                       + prefix[xy[0] - 1, xy[1] - 1];

            Console.WriteLine(result);
        }
    }
}
```

**시간복잡도**

```
합 배열 만들기: O(N²) — 한 번만
쿼리 M개 처리: O(1) × M = O(M)
전체: O(N² + M)
```

행렬 크기가 커도, 쿼리가 몇만 번이어도 충분히 빠르다.

---

2차원 배열 합 문제를 처음 보고 한참 머리를 쥐어짰다. 처음엔 한 줄씩만 받아 계산하는 방법을 생각했는데, 코드가 길어지고 시간복잡도가 커지는 걸 보고 생각을 바꿨다. "두 축으로 더하고 겹치는 부분을 빼준 다음 포함되지 않은 부분을 더한다"는 아이디어까지 도달하니, 그 다음은 금방 식을 유도할 수 있었다. 

```
D[X2][Y2] - D[X1-1][Y2] - D[X2][Y1-1] + D[X1-1][Y1-1]
```
