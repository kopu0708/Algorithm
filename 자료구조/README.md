# 자료구조 
자료구조는 데이터를 효율적으로 다루기 위한 그릇이다. 

코딩테스트에서는 문제에 따라 적절한 자료구조를 골라 다룰 수 있어야 한다.

## 배열과 리스트 
배열과 리스트는 비슷하다. 물론 이제까지 학습한 걸 생각하면 다룰 수 있는 메소드에 차이가 있긴 하지만 말이다.

배열은 메모리의 연속 공간에 값이 채워져 있는 형태이다. 배열의 값은 인덱스를 통해 접근할 수 있다. 선언한 자료형만 저장할 수 있다.

중요한 점은 인덱스는 0부터 시작한다는 점이다. 

한번 크기를 정하면 그 크기를 수정할 수 없으며, 새로운 값을 넣거나 특정 인덱스의 값을 삭제하기 어렵다. 

값을 수정하거나 삭제하기 위해서는 해당 인덱스 주변의 값을 이동시키는 과정이 필요하다. 

C#의 리스트는 내부적으로 배열을 사용한다. 그런데 크기를 가변적으로 사용할 수 있다. 

사실 리스트 내부적으로 Add()를 사용하면 복사해서 새로운 배열을 만들고 기존의 것은 버리기 때문이다. (용량이 다 찼을 경우, 용량이 남았다면 그냥 채우기만 함)

Remove() 같은 경우는 해당 인덱스의 값을 지우고 뒤에 있는 값들을 한 칸씩 당겨온다.

연결 리스트(Linked List)라는 것이 있는데 배열과 List<T>와는 전혀 다른 자료구조이다. 

구조는 다음과 같으며 Head → [값1|다음주소] → [값2|다음주소] → [값3|다음주소] → null 

각 요소를 노드라고 부른다. 노드는 값과 주소(포인터)를 가지고 있다. 또한 메모리가 흩어져 있다. 서로를 포인터로만 연결한다.

그래서 인덱스 접근이 느리며 반대로 삽입/삭제 속도가 빠르다. 리스트와 연결 리스트의 장단점을 반대라고 생각하면 되겠다.

근데 연결 리스트는 진짜 지금 처음 봄 

## 구간 합 알고리즘 
구간합은 배열을 이용해서 시간 복잡도를 더 줄이기 위한 알고리즘이다. 코테에서 사용 빈도가 높다고 한다. 

배열의 특정 구간 합(연속된 부분)을 구하는 걸 말한다. 

{2, 3, 4, 5, 6} 이렇게 있으면 1번째 인덱스 부터 3번째 인덱스까지의 합을 구하는 거다.

매번 구간이 주어질 때마다 그 구간을 처음부터 다시 더하면: 
```C#
static int RangeSum(int[] arr, int start, int end)
{
    int sum = 0;
    for (int i = start; i <= end; i++)
    {
        sum += arr[i];
    }
    return sum;
}
```
이건 한번 할 때마다 O(N)인데 이걸 수만 번 반복하면 시간 복잡도가 O(N * 질문 횟수)가 되어서 시간 초과가 난다.

그래서 배열을 하나 더 만들어서 각 인덱스의 합을 저장해두는 것이다. 

{1,2,3,4,5} 이면 {0,1,3,6,10,15} 이런 배열을 만들어 둔다. 이걸 합배열 이라고 한다. 

이렇게 구해두면 이후 어떤 구간이든 뺄셈 한번으로 바로 해당 구간의 합을 구할 수 있다.

S[i] = A[0] + A[1] + ... + A[i-1] + A[i]라고 할 때 

S[j] - S[i-1] 은 i에서 j까지의 구간 합이 되겠다. 이렇게 합 배열을 구해두면 시간 복잡도가 O(1)로 감소한다. 

이를 코드로 옮겨보면 

```C#
using System;

class Program
{
    static void Main(string[] args)
    {
        int[] arr = { 1, 2, 3, 4, 5 };
        int[] prefix = new int[arr.Length + 1];

        for (int i = 0; i < arr.Length; i++)
        {
            prefix[i + 1] = prefix[i] + arr[i];
        }
        // prefix = [0, 1, 3, 6, 10, 15]

        // 1번째부터 3번째 인덱스까지의 합 (2+3+4=9)
        Console.WriteLine(RangeSum(prefix, 1, 3));  // 9
    }

    // S[j+1] - S[i] = arr[i]부터 arr[j]까지의 구간 합
    static int RangeSum(int[] prefix, int i, int j)
    {
        return prefix[j + 1] - prefix[i];
    }
}
```
이런 형태이다. 합배열을 만들 때에는 원본 배열보다 한칸 크게 만들어야 한다.
