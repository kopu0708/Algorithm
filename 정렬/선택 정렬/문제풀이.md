# 선택 정렬

가장 크거나 작은 데이터를 나열된 순으로 찾아가며 선택하는 방법이다. 

선택 정렬은 복잡하고 시간 복잡도도 O(n^2)으로 오래 걸려서 잘 안 쓰는 방법이라고 한다.

원리만 알아보고 넘어가자 

## 핵심 이론 
최솟값이나 최댓값을 찾고, 남은 정렬 부분의 가장 앞의 있는 데이터와 swap하는 것이 핵심이다. 

원리는 간단하지만 아무래도 정렬을 수행할 때마다 탐색 범위를 줄여나가는 로직 때문에 조금 더 복잡해지는 것 같다.

### 문제 풀이
문제가 하나라 기본 구현이랑 한번에 가겠다. 

```c#
using System;
using System.Linq;

class Program
{
    static void Main()
    {
        string input = Console.ReadLine();
        int[] arr = new int[input.Length];

        for(int i = 0; i < input.Length; i++)
        {
            arr[i] = input[i] - '0';
        }

        int temp = 0;
        int idx = 0;
        for(int i = 0; i < input.Length; i++)
        {
            idx = i;
            int max = arr[i];
            for (int j = i + 1; j < input.Length; j++)
            {
                if (arr[j] > max)
                {
                    max = arr[j];
                    idx = j;
                }
            }

            temp = arr[i];
            arr[i] = max;
            arr[idx] = temp;
           
        }

        foreach(int a in arr)
        {
            Console.WriteLine(a);
        }
    }
}
```
공백 없이 입력을 받아 내림차순으로 정렬하는 프로그램이다. 전체를 순회 하면서도 최대값을 찾는 범위를 하나씩 줄여나가는 것을 볼 수 있다.
