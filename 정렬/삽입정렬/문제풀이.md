# 삽입정렬

삽입 정렬은 이미 정렬된 데이터 범위에 정렬되지 않은 데이터의 적절한 위치를 찾아 삽입하는 정렬이다.

시간 복잡도가 O(N^2)으로 느린편이다. 

하지만 어느 정도 정렬이 끝난 경우 O(N)으로 속도가 빨라져 실무에서 가끔 사용되기도 한다.

정렬 수행 방식을 보면 
1. 현재 index에 있는 데이터 값을 선택한다.
2. 현재 선택한 데이터가 정렬된 범위에 삽입될 위치를 찾는다.
3. 삽입 위치부터 index에 있는 위치까지 shift 연산을 수행한다.
4. 삽입 위치에 현재 선택한 데이터를 삽입하고 index++ 연산을 수행한다.
5. 전체 데이터의 크기만큼 반복한다.

이런 순서로 이루어진다. 바로 문제를 풀어 보자 

## 문제풀이
ATM 인출 시간 계산하기라는 문제인데 각 N명의 인원이 각각 돈을 인출하는 시간을 입력 받아 가장 빠르게 돈을 인출하는 시간을 계산하는 문제이다.

여기서 시간 계산은 예를 들어 {2,4,3} 순으로 3명이 섰다고 치면, 2 + 6 + 9 = 17 이(가) 된다.

 이와 같이 뒷 사람의 인출 시간은 누적되어 오기에 오름차순으로 정렬되어야 가장 빠르게 인출하는 시간을 계산 할 수 있다.

인출 시간이 오름차순으로 정렬되어야 함으로 여기서 삽입 정렬을 이용해 정렬 시킨 후 시간을 계산해야 할 듯 하다. 

물론 다른 방법으로도 정렬하여 풀 수 있겠지만 지금은 삽입정렬을 이용해 풀겠다. (삽입정렬을 배우는 중이니깐) 

```c#
using System;
using System.Linq;  

class Program
{
    static void Main()
    {
        int N = int.Parse(Console.ReadLine());
        string input = Console.ReadLine();
        int[] arr = new int[N];
        arr = Array.ConvertAll(input.Split(' '), int.Parse);

       
        for(int i = 0; i < arr.Length - 1; i++)
        {
            int select = arr[i + 1];
            int j = i;  // 정렬된 범위

            while(j >= 0 && arr[j] > select)
            {
                arr[j + 1] = arr[j];
                j--;
            }
            arr[j + 1] = select;
        }

        int[] prefix = new int[arr.Length + 1];

        for(int i = 1; i < prefix.Length; i++)
        {
            prefix[i] = prefix[i - 1] + arr[i - 1]; // 합 배열 만들기 
        }

        Console.WriteLine(prefix.Sum()); 
    }
}
```
전에 배웠던 합 배열이 다시 나왔다. 정렬을 시켜준 뒤 합 배열을 만들어 그 배열의 합을 구해주는 프로그램이다.

정렬은 선택된 값을 복사해두고 만약 선택된 값이 바로 직전의 값보다 작다면 왼쪽으로 한 칸씩 선택된 인덱스까지 밀어준다. 그리고 생긴 빈칸에 선택된 값을 넣어준다.
