# 퀵 정렬 (Quick Sort)

> 퀵 정렬은 조금 복잡하다. 기준값을 정한 뒤, 그 값보다 작은 데이터와 큰 데이터로 분류하는 것을 반복해 정렬한다.

## 핵심 아이디어

**pivot(기준값)**을 하나 정하고, 그 값보다 작은 데이터와 큰 데이터로 나누는 걸 반복해서 정렬한다.

## 시간복잡도

기준값(pivot)을 어떻게 선정하느냐에 따라 시간복잡도가 크게 달라진다.

| 경우 | 시간복잡도 |
|------|-----------|
| 평균적인 경우 | O(N log N) |
| 최악의 경우 (pivot 선정이 안 좋을 때) | O(N²) |

## 분리 과정 (Partition)

말로만 들으면 잘 안 와닿으니 과정을 순서대로 나열해본다.

**1단계 — pivot(기준값)을 정한다.**

**2단계 — pivot을 기준으로 아래 과정을 거쳐 데이터를 두 집합으로 분리한다.**

| 단계 | 내용 |
|------|------|
| 2-a | `start`가 가리키는 데이터가 pivot보다 **작으면** → `start`를 오른쪽으로 1칸 이동 |
| 2-b | `end`가 가리키는 데이터가 pivot보다 **크면** → `end`를 왼쪽으로 1칸 이동 |
| 2-c | `start`가 가리키는 데이터가 pivot보다 **크고**, `end`가 가리키는 데이터가 pivot보다 **작으면** → 두 데이터를 `swap`하고, `start`는 오른쪽으로, `end`는 왼쪽으로 1칸씩 이동 |
| 2-d | `start`와 `end`가 만날 때까지 2-a ~ 2-c를 반복 |
| 2-e | `start`와 `end`가 만나면, 만난 지점의 데이터와 pivot을 비교해서 pivot이 크면 만난 지점의 **오른쪽**에, 작으면 **왼쪽**에 pivot을 삽입 |

> 💡 실제 구현 시에는 시간복잡도를 위해 "삽입" 대신 **pivot과 교차 지점의 데이터를 swap**하는 방식을 더 일반적으로 사용한다.
