# 정렬 

정렬은 데이터를 정해진 기준에 따라 의미 있는 구조로 재설정하는 것을 말한다.

정렬에는 여러가지 방식이 있다. 

# 정렬 알고리즘 비교

| 정렬 | 핵심 동작 | 시간복잡도(평균) | 시간복잡도(최악) | 안정 정렬 |
|---|---|:---:|:---:|:---:|
| 버블(Bubble) | 인접한 요소를 비교하고 swap 연산으로 정렬 | O(n²) | O(n²) | ✅ |
| 선택(Selection) | 대상에서 가장 크거나 작은 데이터를 찾아 선택하는 과정을 반복 | O(n²) | O(n²) | ❌ |
| 삽입(Insertion) | 정렬된 영역에서 선택 데이터의 적절한 위치를 찾아 삽입 | O(n²) | O(n²) | ✅ |
| 퀵(Quick) | pivot 값을 선정해 기준으로 좌우 분할하며 정렬 | O(n log n) | O(n²) | ❌ |
| 병합(Merge) | 이미 정렬된 부분 집합들을 효율적으로 병합 | O(n log n) | O(n log n) | ✅ |
| 기수(Radix) | 데이터의 자릿수를 바탕으로 비교해 정렬 | O(nk)* | O(nk)* | ✅ |

*k = 자릿수(또는 최대값의 자리 수)
